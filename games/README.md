# games/

这个文件夹存放**真正动手写的游戏**。

规则：**一个游戏一个子文件夹**，这样以后每个游戏都能单独发布到 GitHub Pages。

```
games/
├── 接水果/          # 第一个游戏
│   ├── index.html
│   └── 笔记.md
└── 打砖块/          # 第二个游戏
    ├── index.html
    └── 笔记.md
```

## 命名建议

- 用中文名，一眼就知道是什么
- 不带空格，避免命令行和网址出麻烦

## 每个游戏记得配一份笔记

在游戏文件夹里放一个 `笔记.md`，写清楚：

- 这个游戏做出来了吗？实现了哪些功能？
- 遇到了什么 bug？怎么解决的？
- 下次想加什么？

**记录踩坑的过程，比记录成功更重要。**
