## 技术选择：为什么先做网页游戏

做游戏的方案很多，对新手门槛差别很大：

| 方案 | 门槛 | 什么时候用 |
|---|---|---|
| **HTML5 + Canvas + JavaScript** | ⭐ 最低 | ✅ 现在开始 —— 浏览器直接跑，不用装软件 |
| Python + pygame | ⭐⭐ | 想做带精灵、关卡、音效的完整游戏 |
| Unity / Godot | ⭐⭐⭐⭐ | 想做 3D，或发布到应用商店 |

先用 Canvas 打通「游戏循环 → 画面 → 输入 → 碰撞 → 发布」这条完整链路。学完这些概念，换到任何引擎都是水到渠成 —— 引擎只是替你写好了循环、精灵和碰撞而已。

## 怎么用 AI 帮自己学

学做游戏特别适合用 AI 陪练，但要**先自己试**，再问 AI：

1. **先卡 20 分钟** —— 至少自己读一遍报错、画个流程图
2. **描述思路让 AI 点评**，而不是直接要代码
   > 「我想用 delta time 让小球匀速移动，我的理解是这样……哪里不对？」
3. **拿到代码逐行读懂** —— 看不懂就立刻问，读不懂等于没学
4. **让 AI 出题考你** —— 「根据我刚学的碰撞检测，出一道变式题」
